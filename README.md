# Call of Cthulhu: Colour Out of Space

> The blasted heath. A violet that is not quite a colour, a sick glow in the well, and everything slowly turning grey.

An [Omarchy](https://omarchy.org) theme from the *Call of Cthulhu* trilogy:

- **Call of Cthulhu: Deep One** — black water off Innsmouth, eldritch green witch-light.
- **Call of Cthulhu: R'lyeh** — the drowned city, cold abyssal blue and cyan.
- **Call of Cthulhu: Colour Out of Space** — the blasted heath, a violet that is not quite a colour.

![Preview](preview.png)

## Install

```bash
omarchy theme install https://github.com/sonderbydk/omarchy-call-of-cthulhu-colour-out-of-space-theme.git
```

Then pick it in the theme switcher (`Super + Ctrl + Shift + Space`) or run:

```bash
omarchy theme set "Call of Cthulhu: Colour Out of Space"
```

## What you get

- `colors.toml` palette that Omarchy renders into every terminal (Alacritty, Ghostty, Kitty, Foot), btop, Hyprland borders, the Omarchy shell, Chromium, VS Code, Neovim, Obsidian and keyboard RGB.
- Four 3840×2160 wallpapers in `backgrounds/`, composed so they crop cleanly to 16:10 laptops.
- A matching lock-screen logo and a gradient active-window border.
- Icon theme: `Yaru-purple-dark`.
